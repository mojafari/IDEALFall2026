# Sample ArUco Markers

Ready-to-print markers from the `DICT_4X4_50` dictionary for IDs 0 to 4, in PDF, PNG, and JPG formats. Print the PDFs on letter paper and use them with [`test_Aruco.py`](../../test_Aruco.py). See the [main ArUco README](../../README.md#marker-ids-and-commands) for what each ID does.
