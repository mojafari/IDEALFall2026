# Activity 02: Introduction to Prompting

## What Is a Prompt?

A prompt is the instruction, question, or information that you provide to an AI system.

For example:

````text
Explain Python loops.
````

is a prompt.

So is:

````text
I am a first-year college student.

Explain Python for loops using a drone flight-path example.

Use simple language and provide one short example.
````

----

## Experiment 1

Ask AI:

````text
Explain Python loops.
````

Give it your Tello program.

Read the response.

----


## Experiment 2

Now ask:

````text
I am a first-year college student learning Python.

Explain this Tello program to me.

Focus on:

- Python concepts
- drone actions
- movement commands

Use simple language.

Do not modify the code.
````

Compare the two responses.

----

## What Changed?

The second prompt provides more context.

A useful prompt often includes:

````text
Context
   ↓
Task
   ↓
Requirements
   ↓
Constraints
   ↓
Expected Output
````

----

## Prompt Structure

### 1. Context

Tell the AI who you are and what you are doing.

Example:

````text
I am a first-year college student learning Python and drone programming.
````

----

### 2. Task

Tell the AI what you want.

Example:

````text
Explain this Tello program.
````

----

### 3. Requirements

Tell the AI what to focus on.

Example:

````text
Explain the Python concepts and the physical drone actions.
````

----

### 4. Constraints

Tell the AI what not to do.

Example:

````text
Do not modify the program.
````

----

### 5. Expected Output

Tell the AI what kind of response you want.

Example:

````text
Explain the program step by step using beginner-friendly language.
````

----

## Build Your Own Prompt

Create a prompt asking AI to explain a Python loop.

Your prompt must include:

* Your experience level.
* The topic.
* What you want explained.
* The type of explanation you want.
* Something the AI should not do.

Write your prompt:

````text
[YOUR PROMPT]
````

----

## Prompt Challenge

Start with:

````text
Explain loops.
````

Improve it.

Then improve it again.

Your final prompt should be much more specific.

----

## Reflection

Answer:
1. What changed when you added more context?
2. Did the AI response become more useful?
3. Which part of your prompt made the biggest difference?
4. Does a longer prompt always mean a better prompt?
5. What information does an AI need to understand your task?

----

## Key Idea

Prompt engineering is not about finding magical words.

It is about communicating clearly.

A good prompt is similar to a good engineering specification.
